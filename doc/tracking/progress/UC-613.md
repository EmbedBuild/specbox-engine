## Contexto

Cierre de la única deuda técnica documentada que dejó UC-602: la asimetría nombre↔valor `_NATIVE_RESERVATION_CACHE_KEY = "claim"` en `server/tools/spec_driven.py` (línea 63) + el wire-protocol cross-language Node↔Python↔REST.

UC-602 renombró todo el módulo Python pero no pudo renombrar la key del cache JSON local porque dos consumidores en otro lenguaje (hook Node + endpoint REST) seguirían usando el nombre viejo, rompiendo el spec-guard hook (el guardia que impide escribir código sin UC activo). UC-613 cierra ese círculo con compat bidireccional durante v5.35-v5.36 y eliminación final en UC-612 / v5.37.0.
