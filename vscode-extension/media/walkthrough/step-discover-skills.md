## Explore your new skills

SpecBox installed a suite of agentic skills (slash commands like `/prd`, `/plan`, `/implement`, `/audit`, `/handoff`) along with 20+ enforcement hooks that protect quality automatically.

### Open the SpecBox sidebar

Click the **SpecBox** icon on the activity bar (the left rail) to expand the sidebar. You'll see a **Skills** view grouped into 7 categories:

- **Pipeline** — the spec-driven workflow (`/prd` → `/plan` → `/implement` → `/feedback`)
- **Quality** — `/audit`, `/compliance`, `/quality-gate`, `/acceptance-check`
- **Visual** — `/visual-setup`, `/adapt-ui`, `/check-designs`
- **Tracking** — `/switch-backend`, `/app-init`, `/app-sync`, `/queue-review`
- **Stripe** — `/stripe-connect`, `/stripe-standard`, `/stripe-switch-account`
- **Lifecycle** — `/release`, `/handoff`, `/discovery`, `/quickstart`, `/manual-test`, `/optimize-agents`, `/explore`
- **Other** — any skill installed from a third-party source

### Click any skill to learn more

Clicking a skill opens a card with:

1. **What it does** — a one-sentence overview
2. **When to use it** — typical scenarios
3. **Command** — the exact slash command to paste in the Claude Code chat, with a copy button
4. **Example** — a realistic invocation from a SpecBox project

The card never executes the command — you paste it into Claude Code yourself. That's by design: the sidebar is discovery and reference, not a launcher.
